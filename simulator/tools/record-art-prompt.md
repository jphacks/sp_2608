# 道のレコードのラベルの絵を、画像生成 AI で作るときの指示

Canva の画像生成が使えないときに、ほかの画像生成 AI（Gemini、ChatGPT など）で同じ見た目の絵を作るための指示です。

## 渡すもの

1. **元の写真:** その道の写真。加工してよい条件（CC BY・CC0・パブリックドメイン）のものだけ。CC BY-SA は、作った絵も同じ条件で公開しなければならないので使わない
2. **見本の絵:** `public/records/art/` の PNG のうち、3枚くらい（例：`shakotan-coast.png`、`shiretoko-crossing.png`、`road-to-sky.png`）。透明な部分は白として見せる
3. **下の指示文**

## 指示文（そのまま貼る）

```
1枚目の写真の景色を、2〜4枚目の見本と同じ画風のイラストにしてください。

- 黒一色の版画（木版画・リノカット）風の線画。白地に黒い線と黒い面だけで、灰色や色は使わない
- 正方形。写真と同じ構図で、道・山・海・湖・木など景色の形が分かるように
- 線ははっきり太めに。細かすぎる模様は避ける（直径 9cm ほどの円に縮めて使うため）
- 人、車、看板、文字、ロゴは描かない
- 枠や飾りは付けない
```

## 作ったあと

```sh
python3 simulator/tools/record_art.py 作った絵.png simulator/public/records/art/<道の id>.png
```

白を透明にし、黒をアプリの墨の色（#1e2a24）にした 600×600 の PNG になります。元の写真の作者・ライセンス・ページは、`src/badges.ts` の道の項目に書きます（CC BY は、作者の表示と、加工したことの表示が要る）。
