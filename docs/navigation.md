# ナビの操作と表示

初回のAPI構築・端末への導入は[環境構築](environment-setup.md)、探索・評価の仕様は[経路探索アルゴリズム](route-algorithm.md)を参照してください。操作は停車中に行います。

## 目的地を選ぶ

ナビ画面上部の検索アイコンから、地名・施設を検索します。地図のタップでも選べます。`GEOCODING_URL`未指定では、PC上の北海道OSM検索を使います。別のNominatim互換検索先も設定できます。

現在地は青い点、目的地はピンです。経路は縁取り付きの青緑の線で描き、案内中は通過した区間をグレーに変えます。GPS取得前の初期表示は札幌にしてあります。

| 操作・状態 | 測位の条件 |
| --- | --- |
| ルート検索 | 2分以内・精度500m以内。未取得なら最大15秒待つ |
| 案内開始 | 30秒以内・精度100m以内 |
| 右左折案内 | 10秒以内・精度40m以内 |
| 前回の位置 | 10秒以上更新がなければ灰色で区別 |

位置情報の権限と端末の位置情報設定を有効にしてください。測位精度と取得からの時間は画面で確認できます。「現在地」で追従を再開します。測位は地図表示中と案内中に行います。

## 探索条件

### 目的地を設定する場合→「目的地あり」をタップ
目的地ありでは、同じ道路条件の基準経路に対する追加走行時間を寄り道上限にします。上限は最大6時間です。

### 周遊をする場合→「周遊」をタップ
周遊は出発地へ戻る総時間予算を使い、ドライブルートを提案します。

### 「通常」モードについて
「通常」は景観探索を使わず、「海沿い」「森林」などは景観比重のプリセットです。「かんたん探索」は選んだプリセットで直ちに検索します。


###「好みを調整」について
以下の条件を設定できます。

| 設定 | 意味 |
| --- | --- |
| 海・森林・湖と池・川・渓谷・開けた自然・田園・市街地 | 相対的な優先度。合計100でなくてもサーバーで正規化 |
| 景色の変化 | 景観カテゴリや確認情報のある見通しの変化 |
| 助手席からの眺め | 水域方向と進行方向・座席側の対応 |
| 名道を優先 | 出典と対象区間を確認した登録道路の評価 |
| 夜間補正 | 通過時刻の明るさを景観評価へ反映するか |

0はその特徴を目的にしない設定で、その場所を通行禁止にするものではありません。景観が全項目0の場合は適用・探索できません。名道の値が0でも基本加点は残ります。

バーを動かすだけではAPIを呼びません。「設定を適用」は条件だけを変更し、「この設定で探索」は検索も開始します。プリセットの変更は寄り道上限・道路条件・休憩条件・夜間補正を変更しません。
条件を変更したら古いプレビューを無効化します。設定は画面再生成に対応しますが、名前付きプリセットの永続保存・端末間同期はありません。

## 候補の比較

基準ルートと提案候補の時間・距離・景観・名道・追加時間を比べられます。候補は最大6案で、計算予算や成立条件によって少なくなることがあります。
有効な案を先に表示し、探索中は改善後の候補へ更新します。候補ブロックを押すと、そのルートの詳細を開きます。


## 景観・環境タイムライン

同じ経路上の距離へ、各位置の推定通過時刻と環境を対応付けます。

| 表示 | 確認できること |
| --- | --- |
| 主な景観 | 海・森林・自然などの主要分類と対応区間 |
| 名道 | 4ランクを一本の色分け線で表示。名称・ランク・地図位置 |
| 太陽 | 通過時刻ごとの高度・方位、日中・朝夕・夜 |
| 予報 | 雲量・降水・視程・気温・雪・風と未取得の区別 |
| 湖・川・渓谷 | 近接特徴を独立した帯で表示 |
| 街度 | 建物被覆率。街並みの美しさとは別 |
| 見どころ候補 | 最大4地点の推定根拠・通過時刻・地図位置 |

帯や名道の地点を押すと地図上の位置を確認できます。詳細から地図を見ても、親の詳細パネルは閉じません。
表示用サンプルは最大192区間で、短い橋や一瞬の眺めをすべて捕捉するものではありません。環境情報のない旧結果では帯を省略します。

時刻は候補自身のValhallaの区間時間から補間し、休憩の滞在時間を加えます。渋滞・停車・遅延を常時反映する仕様ではありません。
予報の範囲外・未取得を快晴に置き換えません。朝夕の表示は太陽高度によるもので、朝焼け・夕焼けの発生予報ではありません。見どころは眺望の推定で、安全な停車・撮影地点の推薦ではありません。

## 案内と接続設定

選択した経路で「案内を開始」を押します。スマホとAndroid Autoは同じ案内状態を使います。次の操作・残り時間・距離・音声切替・終了は案内画面に表示します。

車載画面では、案内のカードはAndroid Autoが描くため大きさを指定できません。こちらが扱えるのは地図の面で、拡大・縮小・現在地のボタンを置き、案内中は現在地を追います。速度が上がるほど引いて傾け、止まると寄ります。経路の景観が分かる場合は、ルート線を景観の分類で塗り分け、ルート確認とホームには主な景観の内訳を距離の長い順に出します。走る順序ではありません。走行中は、海が開ける地点の手前と、名前の付いた道に入ったときだけ数秒の知らせを出します。常時出す帯は置きません。

背景地図はMapLibreとOpenFreeMapを使用します。`MAP_STYLE_URL`で差し替えでき、明示的な空欄では無効にします。Valhallaは背景地図を配信しません。地図配信先に経路APIのトークンは送りません。

認証・道路条件・音声案内は設定画面にまとめています。URLを変えた場合はAPKの再ビルドが必要です。エラーの切り分けは[環境構築13章](environment-setup.md#13-エラーの切り分け)を参照してください。
