# 旅れこ プライバシーポリシー

制定日：2026年10月21日

旅れこ（以下「本アプリ」）は、Masaharu Sukekawa（以下「運営者」）が提供する、Android と Android Auto で使うドライブ用のアプリです。このポリシーでは、本アプリが扱う情報と、その使いみち・送り先・保存期間を説明します。

本アプリには、本アプリ独自のアカウントはありません。広告・利用状況の分析・クラッシュレポートの仕組みも組み込んでいません。

## 1. 扱う情報と使いみち

### 位置情報

- **使いみち**：現在地の表示、経路の検索、案内、旅の記録に使います。
- **取得するとき**：アプリを使っている間と、案内中だけ取得します。バックグラウンドの位置情報の権限は求めません。
- **送る情報**：経路を調べるときに、出発地・経由地・目的地の座標と出発時刻を、運営者の経路サーバーへ送ります。
- **天気の取得**：景観に合う道を選ぶため、次の座標を天気予報サービスの Open-Meteo へ送ります。
  - スマートフォンからは、現在地を約1kmの精度に丸めた座標を送ります。
  - 経路サーバーからは、出発地・目的地・途中の地点を約10kmの精度に丸めた座標を送ります。

### 目的地の検索に入力した文字

場所を探すため、運営者の経路サーバーへ送ります。検索は運営者のサーバーの中だけで行い、ほかの検索サービスには送りません。

### マイクの音声

- **使いみち**：車内で会話しているかどうかを判定し、音楽の音量と選曲に使います。
- **端末の外に出さないもの**：音声そのものは端末の中だけで処理し、録音・保存・送信はしません。
- **送るもの**：判定の結果だけを送ります。送るのは、車内のにぎやかさの段階と、1分ごとの会話していた時間の割合です。

### 写真

- **選ぶ写真**：旅のステッカーを作るとき、利用者が選んだ1枚だけを読み込みます。写真の一覧を勝手に読み取ることはしません。
- **位置情報**：写真に撮影場所の位置情報があれば、旅の記録に使います。
- **送るもの**：旅の共有ページに載せるため、絵柄に加工した写真を送ります。加工した写真には撮影場所などの付加情報を含めません。撮影場所の座標は、旅の記録の一部として送ります。

### 旅の記録

旅の記録として、次の情報を端末に保存します。
- 案内中に走った道のり
- 出発・到着の時刻
- 距離と所要時間
- 目的地
- 利用者が入力した地名
- 同乗者の名前（呼び名）

ステッカーを保存すると、旅の共有ページを作るため、この記録と加工した写真を運営者のサーバーへ送ります。

### 音楽（Spotify）

- **ログイン**：Spotify と連携すると、Spotify のログイン画面で利用者が許可した範囲で、再生の操作とプレイリストの読み取りを行います。Spotify のパスワードを本アプリが受け取ることはありません。ログイン情報は端末の中に暗号化して保存します。
- **選曲に送るもの**：曲を選ぶため、次の情報を運営者のサーバーへ送ります。
  - プレイリストの曲名とアーティスト名
  - 同乗者の呼び名
  - そのドライブで再生した曲
  - 経路沿いの景観
- **記録に送るもの**：案内が終わると、再生した曲と会話の割合を旅の記録に添えて送ります。

### 同乗者からの曲のリクエスト

- **入力するもの**：同乗者は、QRコードから開いたページで、呼び名と聞きたい曲を入力します。アプリのインストールやログインは要りません。
- **保存するもの**：呼び名と、ブラウザごとの識別子は、同乗者のブラウザに保存します。
- **サーバーに残るもの**：受け付けたリクエストは、運営者のサーバーに一時的に残ります。

### 窓の操作機器（Bluetooth）

対応する専用機器と Bluetooth でつなぎ、窓の操作と車内の空気の計測値のやりとりをします。このやりとりは端末と機器の間だけで行い、端末の外には送りません。

### 端末の識別子

本アプリをインストールしたときに、無作為な識別子を作ります。旅の記録と音楽の記録を同じ端末のものとしてまとめるために、記録と一緒に送ります。氏名や電話番号などとは結びつけません。

## 2. 送り先

| 送り先 | 送る情報 | 目的 |
| --- | --- | --- |
| 運営者の経路サーバー（Google Cloud Run、東京リージョン） | 出発地・目的地などの座標、検索の文字、選曲に使う情報、曲のリクエスト | 経路の検索、選曲、リクエストの受け付け |
| 運営者の共有ページのサーバー（Cloudflare） | 旅の記録、加工した写真、音楽の記録、端末の識別子 | 旅の共有ページの表示 |
| Open-Meteo | 丸めた位置座標 | 天気の取得 |
| OpenFreeMap | 地図を表示する範囲（地図画像の取得） | 地図の表示 |
| Spotify | Spotify の操作に必要な情報 | 音楽の再生 |
| Google（Gemini API） | プレイリストの曲名とアーティスト名だけ | 曲の雰囲気の判定 |

上の表のほかに、情報を第三者へ販売・提供することはありません。ただし、法令に基づいて求められた場合を除きます。

Google Cloud と Cloudflare は、運営者のサーバーを動かす事業者として、通信の記録を一定期間残すことがあります。この記録には、接続元の IP アドレスや、要求した URL（検索の文字を含む）が入ります。

## 3. 旅の共有ページ

- ステッカーの QR コードから開く旅の共有ページは、そのページの URL を知っている人なら誰でも見られます。QR コードを読み取った人や、URL を転送された人も見られます。
- ページに載るのは、次の情報です。
  - 走った道のりの地図（出発地を含む）
  - 目的地と地名
  - 同乗者の呼び名
  - 写真と撮影場所
  - 再生した曲
  - 会話の割合のグラフ
- リンクは推測できない文字列にしていて、検索エンジンには載らないように設定しています。
- ステッカーや QR コード、URL を人に渡すときは、これらが見られることにご注意ください。
- 共有ページは、運営の都合により、予告なく消えることがあります。残しておきたい写真などは、端末にも保存しておいてください。

## 4. 保存期間

| 情報 | 保存期間 |
| --- | --- |
| 経路の検索の内容 | 運営者のサーバーで最長1時間 |
| 曲のリクエストの受け付け | 受け付けの開始から12時間で終わり、その後、運営者のサーバーから順次消します |
| 旅の記録・写真・音楽の記録（共有ページ） | 期限は決めていません。削除の依頼を受けたときに消します。また、運営の都合により予告なく消えることがあります |
| 端末の中の旅の記録 | 本アプリをアンインストールするまで保存します |

## 5. 削除の依頼

- 旅の共有ページの情報を消したいときは、下の問い合わせ先へご連絡ください。
- 連絡するときは、消したい旅の共有ページのリンクを添えてください。
- 確認できしだい、旅の記録・写真・音楽の記録を運営者のサーバーから削除します。
- 端末の中の情報は、本アプリをアンインストールすると消えます。
- Spotify との連携は、本アプリの「連携解除」からいつでも解除できます。

## 6. 端末のバックアップ

利用者が Android のバックアップを有効にしている場合、端末の中の旅の記録などは、利用者の Google アカウントにバックアップされることがあります。ログイン情報は対象外です。

本アプリは、子ども向けに作ったものではありません。
