# 旅のステッカー

到着した旅の記録に写真・地名・メンバーを加え、L判に4枚並べたステッカーを作ります。

## 使い方

1. 案内終了時の「思い出をつくる」、または「旅の記録」のカードから開く。
2. 写真を選び、水彩・ポスター風・フィルムカメラ風から選ぶ。
3. 地名を編集し、メンバーを入力してキーボードの完了で追加する。名前は×で削除できる。
4. 「シールの画像を保存」、または「コンビニで印刷」を選ぶ。

入力中の地名と名前は、画面を離れるときと書き出す前に確定します。メンバーは20名まで、名前と地名は40文字までです。写真と記録は端末内に残り、次に開いたときに復元します。

## 構成

| 所有先 | 役割 |
| --- | --- |
| `feature/memory` | 記録モデル、走行記録の組み立て、`TripMemoryEditor`の入力確定、`TripMemoryPublisher`の再送管理 |
| `data/memory` | `TripMemoryApi`のHTTP送信と公開ページURLの生成 |
| `platform/android-memory` | ファイル保存、写真加工、描画・書き出し、印刷アプリへの受け渡し、画面 |
| `androidApp` | ナビと記録の接続、保存先の共有、記録一覧への変換 |

`AndroidMemoryRuntime`が保存先と送信処理を共有します。Activityは入力と表示を担当し、写真加工は`PhotoStylizer`、描画は`StickerRenderer`、書き出しは`StickerExporter`へ渡します。

## 走行記録

案内開始から到着までを1件にまとめ、途中で案内をやめた場合は保存しません。時間は実際の経過時間、距離はナビの進捗から積算します。再探索ではそこまでの距離を引き継ぎ、進捗の揺れによる二重計上を避けます。進捗を取得できなければ開始時の計画距離を使います。

端末への保存に失敗した場合は、到着画面に再試行ボタンを表示します。未保存の記録はアプリのプロセス内に保持するため、再試行が終わるまでアプリを強制終了しないでください。

軌跡には精度40m以内・取得後10秒以内のGPSを使い、15m以上離れた点を残します。30秒を超える欠測、位置飛び（推定速度70m/s超）、出発・到着付近の取得漏れがあれば計画経路へ戻します。軌跡の長さが記録距離の80〜120%に収まることも確認します。部分的な軌跡を旅全体として描かず、表示する座標は最大20,000点に抑えます。

## 保存と写真

記録は`filesDir/memories/{id}/`に保存します。

- `memory.json`: 地名・メンバー・走行情報・写真の更新版
- `original.jpg`: 元の写真
- `photo.jpg`: 加工後の写真
- `sheet.jpg`: 印刷用の4面付け画像
- `upload.pending`: Web送信待ちの版

JSONと加工写真は一時ファイルから置き換えます。写真の保存後に一覧へ通知し、表示中のカードだけ長辺512px以下のサムネイルを読み込みます。一覧全体ではBitmapを保持しません。

## WebとQR

Web版は[起動手順](memory-web.md)に従って用意し、`local.properties`に設定してAPKを再ビルドします。

```properties
MEMORY_WEB_URL=https://your-memory-server.example
MEMORY_WEB_TOKEN=Web版のTRIP_UPLOAD_TOKENと同じ値
```

記録は`MEMORY_WEB_URL`の`/api/trips`へ送信し、QRも同じ接続先の`/t/{id}`を使います。音楽ログと同じ端末IDを`X-Device-Id`に付けます。未設定なら送信せず、QRも描きません。トークン付き通信はHTTPSまたは開発用loopbackだけに許可します。

保存・印刷時に送信を予約します。送信に失敗しても端末の画像は残り、次のアプリ起動・書き出し時に再送します。送信中にもう一度書き出しても、新しい送信予約は消しません。送信完了前はQR先の記録が未登録の場合があります。

## 印刷

1コマは44.5×63.5mm、4面付けはL判89×127mm相当（2102×3000px）です。フチなし印刷を考慮し、文字とQRには3mmの余白を取ります。

「コンビニで印刷」で、ネットワークプリントの公式アプリかLINEを選びます。アプリがなければストアを案内します。LINEではネットワークプリント公式アカウントへ画像を送り、発行された番号を店頭で使います。用紙は対応店舗の「シール紙（L判）」を選んでください。

Android 10以上では「シールの画像を保存」で`Pictures/旅れこ`へ保存します。Android 8〜9ではアプリ内保存と印刷アプリへの共有を使います。

## 確認

```sh
./gradlew -g .gradle-local verifyModuleBoundaries \
  :feature:memory:testDebugUnitTest :data:memory:testDebugUnitTest \
  :platform:android-memory:testDebugUnitTest :androidApp:assembleDebug
```

入力の重複、未確定入力の書き出し、写真更新、送信失敗と再送、QRの接続先、GPS欠測を単体テストで確認します。写真選択、Canvasの描画、印刷アプリへの受け渡しは端末で確認します。
