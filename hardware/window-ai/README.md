# 窓AI化（においで助手席の窓が開く）

ホンダ ステップワゴン（RG2）の助手席パワーウィンドウを、ESP32 と においセンサー BME688 で制御するハードウェア一式です。
においが急に強くなると、窓を自動で少しだけ開けます。純正スイッチはそのまま使え、車の配線はギボシでつないでいるので元に戻せます。

## 構成

```
BME688（におい） ─I2C→ ESP32 ─GPIO25/26→ リレーモジュール×2 ─12V→ 車載リレー×2 → 窓モーター
グレー線（IG 12V）→ 端子台 → 管ヒューズ2A → DC-DC（12→5V）→ ESP32・リレーモジュール
```

- 車載リレーは OFF のとき `30–87a` がつながり、純正スイッチの配線がそのまま生きる
- ON にすると `30–87` に切り替わり、モーター線に 12V が入って窓が動く

詳しい配線図は [docs/final-wiring.html](docs/final-wiring.html)（ブラウザで開く）、接続一覧は [docs/wiring.md](docs/wiring.md)。

## 開発環境

- Arduino IDE 2.x ／ ボードパッケージ「esp32 by Espressif Systems」
- ボード：**ESP32 Wrover Module**（Freenove ESP32-WROVER、USBチップ CH340）
- Upload Speed：**115200**（921600 だと書き込みに失敗する）
- Partition Scheme：**Minimal SPIFFS (1.9MB APP with OTA/190KB SPIFFS)**
  （`car_v3_ble` は既定の設定では入らない。「Huge APP」は OTA 領域が無いので選ばない）
- ライブラリ：**Adafruit BME680**（BME688 でも使える）。BLE は ESP32 のコアに入っているので追加不要
- シリアルモニタ：115200 baud

## 安全のためのルール

1. **USB と DC-DC の 5V を同時につながない**。USBで書き込むときは、キーOFFで DC-DC の白（OUT+）を抜いてから
2. 配線をいじるときはキーOFF。12V側を大きく触るときはバッテリーの − を外す
3. 車載リレーは **86（白）＝＋、85（黒）＝−**。逆にするとダイオードで短絡してヒューズが飛ぶ（販売ページの図は逆に描かれているので、本体の表示に従う）
4. **自動で窓を閉める処理は入れない**（挟み込み防止）
5. 上げ・下げのリレーを同時に ON にしない（ファームウェアで防止済み）
6. 走行中のテストは、運転者に操作や画面確認をさせない

## 動作確認済み

- 純正スイッチ（運転席・助手席）で今まで通り開閉できる
- `u` で上げ、`d` で下げ（`SWAP_UPDOWN = false`）
- においを検知すると窓が1.5秒開く
- Wi-Fi経由でログ確認・手動操作・OTA書き込みができる（v2。v3 では `o` を送ったときだけ）
- BLE でアプリと通信できる（v3）
