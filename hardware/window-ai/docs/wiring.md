# 接続一覧

図つきの資料は [final-wiring.html](final-wiring.html) を参照。

## 車の線（ドアのハーネス）

テスターで特定した結果。

| 色 | 役割 | 調べ方 |
|---|---|---|
| グレー | IG電源（キーONのときだけ12V） | 直流電圧、キーON/OFFで変化 |
| 青・赤 | モーター線（2本の間 ≈ 0Ω、アースとは導通なし） | 抵抗 |
| 黒 | アース（ヒンジとの間 ≈ 0Ω） | 抵抗 |
| オレンジ | 運転席スイッチの「上げ」線 | 運転席で上げたときだけ11.2V |

切ったのは **グレー・青・赤の3本だけ**。両端にギボシを付けた（電気が来る側がメス）。

| 線 | メス | オス |
|---|---|---|
| グレー | 車体側 | スイッチ側 |
| 青・赤 | スイッチ側 | モーター側 |

## 12V側

| 番号 | どこから | どこへ | つなぎ方 |
|---|---|---|---|
| ① | グレー（車体側・メス） | 端子台 極1 上 | 2sq中継線。車側オス、端子台側丸端子（エルパ 2-3.5） |
| ② | 端子台 極1 下 | グレー（スイッチ側・オス） | 2sq中継線。端子台側丸端子、反対側メス |
| ③ | 極1上 → 極2上 → 極3上 → 極4上 | | 2sq 渡り線3本（両端丸端子） |
| ④ | 端子台 極4 下 | 管ヒューズ 2A | ホルダーの線を二つ折りにしてネジに挟む |
| ⑤⑧ | ヒューズ出口（メス） | DC-DC IN+（赤）と ⑨ | 2本をまとめてオス1個にかしめる |
| ⑨⑩ | ⑧ | モジュールB COM → モジュールA COM | ジャンパワイヤ。BのCOMに2本入る |
| ⑦ | 端子台 極2 下 | リレーA 87（赤） | 2sq。丸端子＋メス |
| ⑥ | 端子台 極3 下 | リレーB 87（赤） | 同上 |
| ⑪⑫ | 青（スイッチ側）／ 青（モーター側） | リレーA 87a（黄）／ 30（青） | 87aはオス、30はメス（3306） |
| ⑬⑭ | 赤（スイッチ側）／ 赤（モーター側） | リレーB 87a ／ 30 | 同上 |
| ⑮ | モジュールA NO | リレーA 86（白）＋ | |
| ⑯ | モジュールB NO | リレーB 86（白）＋ | |
| ⑰⑱⑲ | リレーA・B 85（黒）− と DC-DC IN−（黒） | ドアのハーネスの黒い線 | 3本を0.5sq延長線とねじってテープ。延長線は黒線の途中の皮をむいて巻きつけ |

- リレーモジュールの **NC は使わない**
- ドアの中に鉄板へ直接留まったボルトがなかったため、アースは純正スイッチのアース線から分岐した

## 5V側

ESP32 はブレッドボードに載せず、ピンにジャンパのメス側を刺す（USB-C を左にした向き）。
ブレッドボードは **左の＋レール＝5V、左の−レール＝GND**。右のレールは使わない。

| 番号 | どこから | どこへ | メモ |
|---|---|---|---|
| ⑳ | DC-DC OUT+（白） | 左の＋レール | 5Vを確認してから。USB給電中はつながない |
| ㉑ | DC-DC OUT−（黒） | 左の−レール | |
| ㉒ | コンデンサ 1000µF | 左の＋と− | 長い足が＋ |
| ㉓㉔ | ESP32 5V ／ GND（上の列） | 左の＋ ／ − | |
| ㉕〜㉘ | モジュールA・B の DC+ ／ DC− | 左の＋ ／ − | トリガーのジャンパは H |
| ㉙ | ESP32 GPIO25 | モジュールA IN | 上げ |
| ㉚ | ESP32 GPIO26 | モジュールB IN | 下げ |

## BME688（ブレッドボード 20〜24行目）

| BME688 | 穴 | 同じ行 |
|---|---|---|
| SCL | a20 | b20 ← ESP32 GPIO22、e20 ← 4.7kΩ |
| SDA | a21 | b21 ← ESP32 GPIO21、d21 ← 4.7kΩ |
| IO4 | （使わない） | |
| GND | a23 | b23 ← ESP32 GND（下の列） |
| 3.3V | a24 | b24 ← ESP32 3.3V（上の列）、d24・e24 ← 抵抗の反対側 |

車では BME688 本体を外し、オス‐メスのジャンパで延長して内張りの穴から顔を出す。
